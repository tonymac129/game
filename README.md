# Mr. Rock

- Mr. Rock is a game where you have to gather resources like wood, stone, and iron to craft different tools and items in order to make miracle potion to save the petrified villagers!
- This game was made in Godot for Haven DC. This represents the theme "bouncing back" because we're both helping the villagers return to normal and making the game work with more than 1.8 million errors :D
- We collaborated by working on different parts of the game like design, gameplay/coding, as well as adding textures and assets to different sprites.
- We learned a lot of new Godot concepts while making the game and learning to fix different bugs.

## Controls

- WASD and arrow keys to move
- Mouse to select different options and interact with objects
- Click and hold to collect different resources
